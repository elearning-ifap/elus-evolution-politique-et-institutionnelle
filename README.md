# Évolution politique et institutionnelle — version GitHub Pages v1.4

Version autonome destinée à être publiée comme site statique sur GitHub Pages.

## Contenu

- `index.html` : module principal
- `assets/` : affiches des cinq vidéos
- `.nojekyll` : désactive le traitement Jekyll de GitHub Pages
- `NOTES_PRODUCTION.md` : notes de production

Les vidéos restent hébergées sur YouTube et sont appelées depuis `youtube-nocookie.com`.

## Publication sur GitHub Pages

1. Créer un dépôt GitHub.
2. Déposer **le contenu de ce dossier à la racine du dépôt**.
3. Dans GitHub : `Settings` → `Pages`.
4. Sous `Build and deployment`, choisir `Deploy from a branch`.
5. Sélectionner la branche `main` et le dossier `/ (root)`.
6. Enregistrer. GitHub fournit ensuite l'adresse publique du site.

## Important

Cette version est conçue pour une consultation hors LMS. Les fonctions SCORM sont inactives lorsqu'aucune API LMS n'est détectée ; le parcours reste consultable dans le navigateur.
